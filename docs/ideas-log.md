## `v0.4-p8` · 키프레임 이동, 기준으로 이동

> 키프레임 오브젝트가 있는(전파 소스) 프레임을 순회하는 기능과 단축키. 현재 프레임에서 앞/뒤로 가장 가까운 곳으로. `[ ]`나 `, .`에.

- `,` / `.` = 가장 가까운 이전 / 다음 ★ 프레임(Frame List `1`이 켜져 있으면 선택한 Object의 ★만). `[ ]`는 문제 프레임(⚠ ✕)이 이미 씀.

> 선택한 프레임으로 이동(S)이 Shift 선택 끝으로 감. 의도는 더블클릭한 위치. F나 R 쪽으로.

- `F` = 기준(◎, 더블클릭한 프레임)으로 이동. 원래 `F`(Show Changes)는 `R`로.

> 단축키 목록을 정리하는 문서.

- [`keymap.md`](keymap.md): 현재 키맵, 비어 있는 키, 제안.

## `v0.4-p10` · 오토 툴은 Fill로 시작

> 오토 툴 종류 변경 시 기본적으로 Fill 모드로.

- 켜거나 다른 도구로 바꾸면 항상 Fill. 같은 도구 안에서 Fill ↔ Paint 전환은 그대로.

## `v0.4-p11` · Object 복제 / 복사 / 병합

> 복제 시 기본은 현재 프레임 마스크만, 전체 링크 마스크 복제는 따로. A의 내용을 B로(Replace / Add). 링크드 오브젝트 병합(A로 오버라이드, B로 오버라이드, Add).

- `Duplicate` = 이 이미지만, `Duplicate All` = 모든 링크 Mask. `Copy A → B…`, `Merge…` 창. (p17에서 다시 정리)

## `v0.4-p13` · 마우스 위치 기준 이동 키

> 프레임 관련 창에 마우스오버된 상태에서는 WASD나 화살표로 이동, 오브젝트 관리도 마찬가지. 그 밖에서는 WASD 미작동, 화살표 위아래 = 오브젝트, 양옆 = 프레임.

- 목록 위: `W A ↑ ←` = 이전, `S D ↓ →` = 다음. 그 밖은 그대로.

> 상단 2줄의 위계: 덜 쓰는 기능은 위, 자주 쓰는 기능은 아래. 단축키를 모를 수 있으니 기능의 존재를 위에서 알리기. 기획 방향성 문서로.

- [`menu-design.md`](menu-design.md). 메뉴 = 모든 명령과 키, 툴바 = 작업 중 토글만.

## `v0.4-p15` · 키와 메뉴 손보기

> Go 메뉴의 Scroll to Current Frame(S)은 F와 겹치고 작동도 안 됨. 빼기.

- 메뉴와 `S` 키 모두 뺌. 스크롤은 ⌖ 버튼.

> V에 매핑된 기능 이름은 상단 메뉴에서 "Final/Object 마스크 토글"로.

- 메뉴 `Toggle Final / Object Mask`, 툴바는 지금 모드(`Preview: Final`).

> X 꾹 누르면 연속으로 바뀜. Z = 홀드, X = 모드 변경, V = 토글로.

- `Z` 누르고 있기 · `X` Final ↔ Object · `V` 켜기/끄기. 토글 키는 누르고 있어도 한 번만.

> 프레임 선택 엔터 말고 스페이스도.

- 프레임 목록 위에서 `Space` = `Enter`(기준 ◎). 캔버스의 Space+드래그는 그대로.

> Paint 버튼으로 넘어가도 A처럼 전체가 찬 상태로 시작.

- Paint 버튼 = `A`.

> 에딧모드 처음 진입하면 브러쉬 켜기. UX 원칙을 세우고 문서로.

- `E` 편집은 브러쉬가 켜진 채 시작. [`ux-principles.md`](ux-principles.md).

## `v0.4-p17` · Objects 패널

> 삭제 시 물어보지 않고 대신 잠금(어차피 언두 됨). 모든 오브젝트 잠금/해제 버튼.

- 삭제는 확인 없이(Ctrl+Z). 행마다 🔒, `🔒 All` / `🔓 All`. 잠긴 Object는 삭제·Merge로 사라지지 않음. 잠금도 Undo, 저장됨.

> 오브젝트 패널에 마우스오버 시 Ctrl+D 복제, Ctrl+Shift+D 링크드 복제.

- 그대로 구현. 메뉴 Edit → Objects에 키 표시.

> 선택 기반 카피는 첫 선택이 소스, 마지막 선택이 타겟. 설명 가능한 걸 선택지로 쥐여주지 않기.
> 머지는 옵션 없이 Add. 옵션을 남기면 "내용만 머지하고 오브젝트는 비우기"도.
> 카피는 Add + 현재 이미지로, 옵션 버튼은 오른쪽에 작게.

- `Copy A → B` / `Merge` = 바로 실행, 옆 `⚙` = 옵션(Copy: Add / Replace, 이 이미지 / 모든 이미지 · Merge: Add / Override A / B / Into A).
  (Copy / Move / Merge 역할 재정리: [`specs/05-merge-copy-move.md`](specs/05-merge-copy-move.md))
