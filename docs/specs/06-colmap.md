# SAM Mask GUI — COLMAP 호환 기획서 (초안)

COLMAP으로 정렬된 3DGS 데이터셋을 그대로 열어 마스크를 만들고, 원하는 양식으로 돌려놓는 기능.
출처: v0.3 요청([`04-v0.3-requests.md`](04-v0.3-requests.md) 마지막 절), 아이디어 "콜맵 호환" 1~8 ([`backlog/ideas.md`](../backlog/ideas.md)).
상태: **확정(2026-09-29)**, 트레이너별 프로필(5장 아래쪽, C4)만 스피큘라 익스포트 프리셋 보고서(GPT 작성 중)를 받은 뒤 채운다.

## 2. 장면(Scene)이란

3DGS 준비 도구(예: Inria `convert.py`)가 만드는 흔한 구조:

```text
<scene>/
├─ images/            학습에 쓰는 이미지 (왜곡 보정 후)
├─ sparse/0/          cameras.bin · images.bin · points3D.bin (또는 .txt)
├─ masks/             (있을 수도) 마스크
├─ input/, distorted/ (있을 수도) 보정 전 원본과 중간 결과
(작업 파일은 장면 **옆** `<scene>.sms/` — 트레이너가 장면 폴더를 통째로 읽어도 섞이지 않게)
```

- **장면으로 인식**: 고른 폴더에 `images/`와 `sparse/*/images.bin|txt`가 있으면. 이미지 폴더(`images/`)를 고른 경우도 부모를 보고 인식.
- 마스크는 `images/`(왜곡 보정 후, 학습에 쓰는 이미지) 기준으로 만든다.
- 인식되면 제목 표시줄과 상태 표시줄에 `COLMAP scene: <이름> · 카메라 N · 이미지 M · 3D 점 K`.
- 이미지 목록은 `images/` 폴더 기준(지금과 같음). `images.bin`에 있는데 파일이 없거나, 파일은 있는데 `images.bin`에 없는 이미지는 Frame List에 ⚠ 표시.

### 2.1 어안 데이터셋 · 카메라 하위 폴더(`cam0/`, `cam1/`) — R1 구현 `v0.4-p132`, R2 `v0.4-p136`, R3 `v0.4-p137`, R4 `v0.4-p138`(2026-10-09)

듀얼 피시아이 같은 리그는 이미지가 카메라별 하위 폴더에 있다(`images/cam0/0001.jpg`, `images/cam1/0001.jpg`).

**지금(`v0.4-p31`부터)**

- 장면이 아닌 폴더는 바로 아래 이미지만 본다. 이미지가 하위 폴더에만 있으면 "No images found".

**어안 데이터셋으로 알아보고 통째로 열기** (사용자 안 10-09, R1 = 1 · 2 · 5 · 8번 구현 p132)

어안 리그 데이터셋을 불러오는 최소 단위는 폴더 넷과 그 안의 파일이다.

```text
<root>/
├─ images/cam0/   images/cam1/    이미지 (image/ 도 같게, 대소문자 무시)
└─ masks/cam0/    masks/cam1/     마스크 (mask/ 도 같게). 없을 수도 있음(처음 마스킹)
```

1. **어디를 골라도 같은 데이터셋**: `<root>`, `images/`, `images/cam0/`, `images/cam1/` 중 무엇을 골라도 위로 최대 두 단계 올라가 `<root>`를 찾고, 카메라 폴더 전부(cam0 + cam1)를 연다. cam0 하나만 골라도 둘 다 연다(짝이 있어야 360 · 스티칭이 맞음). 로그에 `Fisheye dataset <root>: cam0 94 + cam1 94 images, masks cam0 94 + cam1 94`.
2. **알아보는 조건**: `images/` 바로 아래에 카메라 폴더 이름(`cam` 또는 `camera` + 숫자, `_`·`-` 허용, 대소문자 무시)이 **둘 이상** 있고 각각 이미지가 있다. `sparse/`는 있어도 없어도 된다. 다른 이름의 폴더와 더 깊은 폴더는 읽지 않는다(0022 맨 위 같은 큰 폴더는 조건이 안 맞아 지금처럼 막힘).
3. **어안인지 확인**: 폴더 이름만으로는 어안인지 모른다. 모델이 있으면 `cameras.bin`의 카메라 모델(FISHEYE 계열)로, 없으면 Lens edge와 같은 원 찾기(카메라마다 16장 평균, CPU, 몇 초)로 확인한다. 원이 없으면 "카메라 폴더 데이터셋"으로만 열고 어안 기능(Lens edge 기본 켜기 등)은 권하지 않는다. R4 구현 p138: `rig.find_circles`(1/4 크기로 읽어 0022 188장에 1.8초), 결과는 Logs 한 줄과 `MainWindow.rig_circles`. 원이 있으면 Fisheye Lens Edge를 안내.
4. **마스크 불러오기**: `masks/cam0|cam1`을 Object 하나로(3장 규칙, 이름 `masks`). `masks_*/camN`과 `masks/<세트>/camN`도 세트마다 Object 후보로 보여 준다(R2 구현 p136: `rig.mask_sets`, 창 제목 `Masks in this camera rig`, 세트는 `masks/<세트>/`로 보이고 Object 이름은 세트 이름).
5. **누락 없이**: 열 때 검사해 Logs에 ⚠, Frame List에 표시한다.
   - 카메라끼리 짝: cam0에만 / cam1에만 있는 이름.
   - 마스크: 이미지는 있는데 마스크가 없는 것, 마스크만 있는 것(카메라별 수).
   - 모델이 있으면 지금의 모델-이미지 대조도 그대로.
6. **덮어쓰기**: Export Output에 **Into the dataset**(지금의 Into the scene을 모델 없는 데이터셋까지 넓힘). `<root>/masks/camN/`에 쓰고, 바뀌는 파일은 먼저 `<root>/masks_backup_<시각>/camN/`으로 옮긴다(지금 장면과 같은 규칙, 조용히 덮어쓰지 않음). R3 구현 p137: For = `Camera rig dataset`(프리셋 `RIG`, 학습기 프리셋 대신), `rig.RigDataset`이 Export에 장면 자리로 들어감.
7. **새 데이터셋**: 빈 폴더를 고르면 `images/camN`(원본 링크, 안 되면 복사) + `masks/camN` + 모델이 있으면 `sparse/` 복사. 뺀 프레임(Exclude)은 넣지 않음.
8. **작업 파일**: `<root>` 옆 `<root>.sms/`(장면과 같음). 예전에 `cam0` 하나만 열어 만든 `cam0.sms/`가 있으면 이름(`0001.jpg` → `cam0/0001.jpg`)이 달라 자동으로 합치지 않고, 불러올지 묻는다.

변형 구조: 0022 `data\fisheye`(`images/orig/cam0`, `masks/<세트>/cam0`)는 실제 데이터셋 `CAM_…_D_dataset`을 가리키는 정션 모음(참고용)이라 알아보지 않는다(사용자 10-09). 정션을 거쳐 고른 폴더는 실제 경로로 바꿔 열지 검토(작업 파일 `.sms`가 둘로 갈리지 않게).

| | 얻는 것 | 남는 것 · 위험 |
|---|---|---|
| 모델 없는 어안 데이터셋 | 어디를 골라도 cam0 + cam1과 마스크를 한 번에, 누락 검사, 덮어쓰기 · 새 데이터셋 | 360 · Pinhole 변환은 여전히 모델(`cameras.bin`의 렌즈 모양)이 있어야 함 |
| cam0만 골랐을 때 | 짝이 항상 같이 열림 | 한 카메라만 보고 싶을 때는 Frame List에서 거름(따로 열기 옵션은 결정 필요) |
| 큰 폴더를 잘못 고름 | 조건이 안 맞으면 지금처럼 "No images found" | — |
| 다른 이름의 카메라 폴더(`front/`, `back/`, `lens0/`) | — | 안 읽힘. 필요하면 이름 목록을 늘림 |
| 예전 `cam0.sms/` 작업 | 묻고 불러옴 | 이름이 바뀌어 손으로 고른 Object를 다시 맞춰야 할 수 있음 |

모델(`sparse/`)이 있어야만 되는 것(위 안으로도 남는 것):
- **모델-이미지 대조 경고**: 장면을 열면 모델에 적힌 이미지 이름과 실제 파일을 맞춰 보고, 한쪽에만 있는 것을 Logs에 ⚠로 알린다. 모델이 없으면 맞춰 볼 목록이 없다(대신 5번의 카메라 짝 · 마스크 검사).
- **학습기 프리셋**: 장면일 때만 목록에 나온다. 위 안의 Into the dataset · 새 데이터셋은 프리셋 없이 COLMAP 이름 규칙(`<이미지 이름>.png`)으로.
- **변환(360 from camera pairs, Pinhole views)**: 렌즈 모양(카메라 모델)을 모델의 `cameras.bin`에서 읽는다.

단계(안): R1 알아보기 · 통째로 열기 · 누락 검사 → R2 마스크 세트 불러오기 → R3 Into the dataset · 새 데이터셋 → R4 원 찾기로 어안 확인. 각 단계 p태그로 되돌릴 수 있게.

정한 것(10-09): cam0을 골라도 모든 카메라를 연다(따로 여는 옵션 없음, 단 `cam0.sms` 작업이 있으면 묻는다). 카메라 이름은 `cam`/`camera` + 숫자만.

## 3. 열기: 기존 마스크를 Object로

- 장면 안의 마스크 폴더를 찾는다: `masks/`, `masks_*/`, 그리고 사용자가 고른 폴더.
- 파일 매칭: `a.jpg` ↔ `a.jpg.png`(COLMAP 방식) 또는 `a.png`(같은 이름) 둘 다 시도.
- 폴더 하나 = **Object 하나**(이름 = 폴더 이름), 각 이미지의 마스크 = 그 Object의 프레임(상태 ★ 아님, "불러옴").
- **흑백 방향**: 폴더마다 물어본다(흰색 = 대상 / 검정 = 대상). 흰 면적이 대부분이면 "검정 = 대상"을 기본으로 추천.
- 이미 이 장면의 작업 파일이 있으면 다시 불러오지 않고, 메뉴 `File → Import Masks from Folder…`로만 추가.

## 4. 마스크 세트: 여러 폴더로 내보내기 (구현: `v0.4-p25`)

한 장면에서 용도가 다른 마스크를 여러 벌 만든다(예: 사람만 지운 것 / 사람 + 하늘을 지운 것).

| 항목 | 뜻 | 예 |
|---|---|---|
| 이름 | 폴더 이름에 붙는 구분자 | `people` → `masks_people/` |
| Object | 합칠 Object들(체크한 것의 합집합) | Person #1, Person #2 |
| 프로필 | 파일 이름·흑백·형식(5장) | COLMAP |

- 지금의 "Final Mask(체크한 Object 전부)"는 기본 세트 하나로 취급한다(이름 없음 → `masks/`).
- 세트 목록은 작업 파일(`project.json`)에 저장. Export 창에서 세트를 고르거나 전부 내보낸다.
- UI: Export 창 위쪽에 세트 목록(추가 / 이름 바꾸기 / 삭제), 세트를 고르면 Object 체크 목록. 캔버스 Mask Preview에 세트 보기는 넣지 않는다.

- 해상도: 항상 원본 이미지 크기(지금과 같음).

## 6. 프레임 빼기 → 07 6장으로 바뀜 (원본 `.bin`을 고치지 않고 Export 때 걸러 씀)

> 아래는 초안 기록.

흐리거나 가려진 프레임을 학습에서 뺀다.

1. Frame List에서 프레임을 고른다(Shift / Ctrl) → `Frame → Drop from Scene…`.
2. 창: 뺄 프레임 수, **원본 백업**(기본 켬), 3D 점 처리(아래).
3. 실행:
   - 이미지 파일을 `<scene>/_dropped/images/`로 **옮긴다**(지우지 않음). 마스크 파일도 같이.
   - `sparse/0/`을 `sparse/0_backup_<날짜시각>/`으로 복사한 뒤 `images.bin`에서 그 이미지를 뺀다.
   - `points3D.bin`: 뺀 이미지의 관측(track)을 지운다. 관측이 2개 미만으로 줄어든 점은 지운다(COLMAP 관례).
4. Undo: 앱의 `Ctrl+Z`가 아니라 `Frame → Restore Dropped Frames…`(백업에서 되돌림). 파일을 옮기는 동작이라 Undo 스택에 넣지 않는다.

- 백업을 끄면 이미지는 `_dropped/`로 옮기되 `sparse` 백업만 생략(원본 이미지는 여전히 안 지움).
- `.bin` 읽기/쓰기는 COLMAP의 공개 형식을 직접 구현(외부 의존 없이). `.txt` 모델도 같은 방식.

| C2 | 마스크 세트 + 프로필(COLMAP, 같은 이름 PNG)로 내보내기, 장면의 `masks*/`에 쓰기(덮어쓸 때 백업) | 마스크 폴더만 |
| C3 | 프레임 빼기 + `.bin` 수정 + 백업 / 되돌리기 | 예(백업 후) |
| C4 | 트레이너별 프로필 추가(조사 결과대로) | 아니오 |

C1~C2가 먼저, C3는 `.bin` 쓰기라 따로 태그를 두어 쉽게 되돌릴 수 있게 한다.
