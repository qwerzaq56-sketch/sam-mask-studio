오브젝트 외곽까지 마스크를 외부로 자동 확장하는 기능 추가. ( 오브젝트 필? )

브러쉬로 범위 지정해서 해당 범위 내에만 기능 적용하는 부가기능 추가.

기존의 전체적 기능적용은 유지

브러쉬 기능에서 기본 휠은 줌인/줌아웃
컨트롤 + 휠은 크기 조작으로 변경.

--------------------

현재 마스크 에디팅 시 마스크 외곽선 너무 두껍고 보기도 불편함.
다른 잘 구현된 방식 참고해서 바꾸거나,
흰색 아웃라인 한줄로만 표현하고 두께조절, 온오프도 옵션도 넣으면 좋을 듯.

그리고 머지한 레이어에서 작업했을 때
각 레이어에 적용됐던 색이 그대로 남아있어서 보기 불편함.

-------------

배치 마스킹 캔슬했는데 작업이 완전 중단이 안되고 일시정지만 됨.
스탑이랑 캔슬을 따로 둬서 완전 취소도 되게 해야할 듯.

그리고 기존 프롬프트 디텍션 탭과 분리해서 프롬프트도 따로 쓸 수 있게 하는게 나을 듯 함.

------------

오브젝트를 일단 선택해야만 삭제와 같은 버튼이 눌려서 사실상 더블클릭해야함.
불편하니 수정.

선택한 프레임의 오브젝트가 비어있으면
안 보이게 할 수 있는 기능도 추가해야 할듯
기본이 안 보이고 기능 키면 보이게 해야할 것 같은데.

아니면 프레임별 오브젝트가 기본적으로 따로 생성할 수 있게 하고 (연결 안 되어 있고),
그 오브젝트를 전파했을 때만 '오브젝트 ( 링크드 )'로 처리하는게 나을수도.

---------------

프롬프트/디텍션에서 선택한 오브젝트들을 머지해서 하나의 오브젝트로 추가하는 기능 추가.
서치한 각 프롬프트별로 오브젝트를 만들어서 추가하는 기능도 포함.

프롬프트 디텍션으로 찾은 오브젝트를 뷰포트에서
Shift/Ctrl 클릭 및 드래그 조작으로 선택 or 선택해제하는 방식 추가

프롬프트 디텍션 된 마스크 프리뷰 온/오프 버튼 추가

그리고 프롬프트 옆 체크박스 토글할 때 마스크 켜고/꺼지는 거 프리뷰 반영되는 속도가 너무 느린데
느릴 이유가 없는 것 같은데 이유 파악 필요. 이게 특히 불편해서 우선순위 높음.

--------------

최적화 고려. 예상되는 병목 알아서 생각해서.

-----------------

전파 기능에서 범위 설정이 좀 더 직관적이면 좋을 것 같다.
A에서 B까지 Sht 선택해서 설정한다던지, 이미지 썸네일 목록에서 선택한다던지.

이를 위해 프레임 목록을 UI 하단으로 옮기고 썸네일로 가로로 넘겨볼 수 있게 하고,
프롬픝/디텍션/전파/로그UI는 오브젝트/이미지 UI의 하단으로 옮겨도 좋을 듯

---------------------

기본적으로 콜맵 형식을 읽어오고 편집할 수 있도록 개조하면 좋을 것 같다.
이미지 → 마스크를 매칭해서 원본 마스크를 오브젝트로 불러와서 편집하고,
편집된 사항을 bin 파일에도 반영할 수 있게. ( 나중에 프레임 삭제 기능 추가하면 필요 )

이 때 마스크를 여러 버전으로 ( 여러 폴더로 ) 내보낼 수 있으면 좋을 듯.

--------------------

각 변경사항을 나중에 점검했을 때 구현이 이상하면 되돌리기 쉽게끔.
우선순위를 나눠서 몇 단계에 나눠서 구현 진행.
