# 10 · Object 안의 포인트 레이어

> 원래 요청: [`backlog/ideas.md`](../backlog/ideas.md) "포인트 추가"(2026-09-30).
> 코드: `PromptLayer`, `FrameState.layers / layered_mask`(`src/core/project.py`), `Session.active_layer`, Properties의 Points 트리. 구현 `v0.4-p53`.

## 1. 문제

- 기존 마스크(불러온 것, 전파된 것, Apply한 것)에 포인트를 찍으면 SAM2가 그 마스크를 약한 힌트로만 받고 다시 그려서, 마스크의 원래 모양이 망가짐.
- `v0.4-p44`의 Ctrl+클릭(한 점으로 조각 더하기 / 빼기)은 빼기는 쓸 만하지만 더하기가 한 점 조각이라 거침. 포인트를 여러 개 두고 다듬을 수 없음.

## 2. 구조

한 프레임의 마스크 = **Original** + **레이어 1…n**, 그 위에 **Edit Layer**(브러시·오토 툴).

```text
최종 = ((Original ∪ 더하기 레이어들) − 빼기 레이어들) 에 Edit Layer 적용
```

- **Original**: 지금까지의 마스크(포인트 / 박스 / 불러온 마스크 / Variant). 여기서 편집하면 전처럼 기존 마스크를 씨앗으로 SAM2가 다시 그림.
- **레이어**: 자기 포인트·박스만으로 SAM2를 따로 돌린 조각(기존 마스크는 씨앗으로 쓰지 않음). **더하기(+)** 또는 **빼기(−)**.
  빼기 레이어의 +포인트는 "뺄 조각"을 고르고, −포인트는 그 조각을 다듬음. 순서와 상관없이 더하기를 모두 합친 뒤 빼기를 뺌(예측 가능하게).
- 조각은 SAM2의 가장 점수 높은 Variant. 클릭마다 그 레이어만 다시 계산(디코더 한 번, 이미지 임베딩은 이미 있음).

## 3. 어느 레이어에 찍히나

- 지금 레이어(Points 트리에서 굵게)에 찍힘. 트리에서 줄을 누르면 그 레이어로.
- **자동**: 이 프레임의 마스크가 자기 포인트 없이 생긴 것(불러오기 · 전파 · Apply · 특수 Apply)이면 첫 클릭이 **레이어 1(+)**을 만들고 거기에 찍힘.
  자기 포인트로 만든 프레임이면 Original에 찍힘(보통의 SAM2 다듬기).
- 다른 프레임으로 가거나 편집을 다시 시작하면 자동으로 돌아감.

## 4. 화면

- Properties → Mask 탭의 **Points** 칸이 트리: `Original`, `Layer 1 (+)`, `Layer 2 (−)` … 아래에 그 레이어의 포인트 / 박스, 줄마다 **×**(하나씩 삭제).
- 버튼: **+ Layer**(더하기 레이어 추가, 지금 레이어로) · **+ / −**(지금 레이어의 더하기 ↔ 빼기) · **Remove Layer**.
- 캔버스에는 지금 레이어의 포인트 / 박스만(다른 레이어 것까지 보이면 어느 점이 어디에 속하는지 헷갈림).

## 5. 검토한 문제와 결정

| 문제 | 결정 |
|---|---|
| 브러시(Edit Layer)는 무엇에 대한 차이인가 | 레이어까지 합친 마스크에 대한 차이. 레이어를 바꿔도 칠한 것은 위에 그대로 |
| 저장 | 레이어마다 포인트·박스·+/− (json)와 조각 PNG(`<key>.L1.png` …). 예전 프로젝트는 레이어 없이 그대로 읽힘 |
| 전파 | 합친 최종 마스크가 전파됨. 전파된 프레임에는 레이어가 없음(원본 프레임은 레이어 유지) |
| Variant | Original의 Variant만 목록에. 레이어는 최고 점수 조각 |
| Apply Layer(Edit Layer 탭) | 레이어까지 합쳐 새 Original로 굳힘(레이어도 비움) |
| SAM2 로딩 중 | Original은 전처럼 대기열, 레이어 클릭은 "SAM2 loading" 안내(나중에 필요하면 대기열) |
| Undo | 클릭 / 레이어 추가 / 삭제 / +− 전환 각각 한 단계 |
| Ctrl+클릭(`p44`) | 그대로: 한 번에 끝나는 빠른 조각 더하기 / 빼기(Edit Layer에 기록) |
| 계산량 | 클릭한 레이어만 다시 계산. 합치기는 불리언 연산이라 가벼움 |
