# SAM Mask Studio v0.3 진행 현황

**v0.3.0 릴리스 (2026-09-28):** 아래 "완료" 항목 전부(1~5단계)가 `main`에 병합되고 `v0.3.0` 태그가 붙었습니다. 안정판 실행기(`SAM Mask Studio.bat`)도 v0.3.0을 실행합니다. 6단계(COLMAP)는 다음 버전으로 넘어갑니다.

원래 요청 목록: [`docs/specs/04-v0.3-requests.md`](../specs/04-v0.3-requests.md) · 개발 메모(영문): [`docs/DEVELOPMENT.md`](../DEVELOPMENT.md)

- 브랜치 `dev`에서 단계별로 진행하고, 단계마다 `v0.3-pN` 태그를 붙입니다.
- 되돌리기
  - 단계 전체: `git revert -m 1 <병합 커밋>`
  - 병합 없이 dev에 바로 커밋한 변경(2.5와 그 뒤 작은 수정 두 건): `git revert <커밋>`
- 실행
  - `SAM Mask Studio (dev).bat`: 최신 dev
  - `SAM Mask Studio.bat`: 안정판 v0.3.0 (이전 안정판은 태그 `v0.2.0`)

## 완료

### 1단계 · 반응 속도 / 작은 UX 수정 (`v0.3-p1`)
- **프롬프트 체크박스 토글이 느리던 문제 해결**
  - 원인: 체크 하나마다 화면 전체 갱신이 여러 번 돌았습니다. 라벨 체크박스는 후보 수만큼 돌았습니다.
  - 결과: 0.8초 → 0.02초
- **캔버스 오버레이 캐시:** 바뀐 레이어만 다시 그립니다.
- **외곽선:** 흰색 1줄. 줌해도 굵어지지 않고, 툴바에서 켜기/끄기(`O`)와 두께를 조절합니다.
- **에딧 레이어 초록/빨강 표시:** 기본은 끄고, 툴바 `Edit Changes` 또는 `F`로 켜고 끕니다.
- **오브젝트 행 버튼:** 선택 안 된 행의 버튼이 두 번 눌러야 동작하던 문제를 고쳤습니다.
- **배치 마스킹 / 전파:** `Stop`(여기까지 결과 유지)과 `Cancel`(전부 버림)을 분리했습니다.
- **자동 저장:** 백그라운드로 옮겨서, 배치·전파 직후 몇 초씩 멈추던 문제를 없앴습니다.

### 2단계 · 에딧 레이어 도구 (`v0.3-p2` ~ `v0.3-p2.10`)
- **머지 이름:** 처음 선택한 오브젝트의 이름을 씁니다.
- **프로퍼티 창:** `Mask` / `Edit Layer` 탭으로 나누고, 탭마다 스크롤할 수 있습니다.
- **Brush 그룹** (칠하는 즉시 반영)
  - `Paint`: 드래그 = 추가, Alt+드래그 = 빼기. 단축키 `D`.
  - `Restore`: 칠한 곳의 편집을 되돌립니다. 옵션은 `Add` / `Subtract` / `Both`. 칠하는 동안에도 Edit Changes의 초록/빨강이 보이고, 되돌린 부분은 바로 색이 빠집니다.
- **Auto tools:** `Object Fill` / `Fill Holes` / `Remove Specks` / `Grow` / `Shrink`
  - 툴을 누르면 결과를 바로 계산합니다. Object Fill은 백그라운드로 계산합니다.
  - `Fill` 모드(기본): 결과 전체를 마젠타(추가)/보라(제거)로 보여줍니다. 에딧 체인지의 초록/빨강과 구분됩니다.
  - `Paint` 모드:
    - 선택하지 않은 부분은 짙은 회색입니다.
    - 드래그하면 범위가 노란색으로 표시되고, 놓으면 그 부분이 선택되어 마젠타/보라가 됩니다.
    - Alt+드래그는 선택 해제입니다(범위가 빨간색으로 표시).
    - `A`는 전체 선택, 다시 누르면 전체 해제입니다.
    - 선택·해제·전체 선택도 Ctrl+Z / Ctrl+Y로 되돌릴 수 있습니다. 반영한 뒤에는 Ctrl+Z가 반영 자체를 되돌립니다.
  - 반영 (반영할 때마다 Undo 1단계)
    - `Apply & Recompute` 버튼 또는 `Enter`: 반영하고 툴은 유지한 채 다음 결과를 계산합니다. 누를 때마다 한 번씩 더 적용됩니다.
    - Fill / Paint 모드 버튼은 모드 전환만 합니다(이미 선택된 모드를 다시 눌러도 아무 동작 없음).
    - `Apply & Close` 버튼: 반영하고 나갑니다. 두 버튼은 모드 버튼 바로 아래 한 줄에 있습니다.
    - 그 외 모든 나가기(다른 툴, Esc, Finish Editing, 오브젝트 이동): 반영하지 않고 버립니다.
    - 켜진 툴 버튼을 다시 누르면 Esc와 같이 버리고 나갑니다.
  - Fill 모드에서 `A`: 전체가 선택된 상태로 Paint 모드에 들어갑니다(이후 Alt+드래그로 빼기).
  - Edit Changes가 켜져 있으면 오토 툴 프리뷰 중에도 에딧 레이어의 초록/빨강이 함께 보입니다.
  - `Region Box`: 드래그로 범위를 추가하고, Alt+드래그로 뺍니다. 오토 툴은 이 범위 안에서만 동작하고, 리전 조작도 Undo가 됩니다.
  - 설정: 툴마다 따로 가지며 슬라이더 + 입력 칸입니다. 슬라이더 위에서 휠을 굴리면 값은 그대로 두고 패널이 스크롤됩니다.
    - Object Fill: `Max grow`, `Sensitivity`
    - Fill Holes / Remove Specks: `Max size`를 각각 따로 가집니다.
    - Grow / Shrink: 공통 `Amount`
- **파이널 마스크 프리뷰**
  - `Z`를 누르고 있는 동안 보이고, `X`로 켜고 끕니다.
  - 프리뷰 중에도 편집할 수 있고, 브러쉬 반경은 초록색으로 보입니다.
- **Alt 표시:** Alt를 누르고 있으면 브러쉬 반경 원과 리전 박스 드래그 사각형이 빨간색으로 바뀝니다(빼기·선택 해제 구분).
- **조작**
  - 이미지 넘기기: ←/→, PgUp/PgDown (A/D는 제외). Edit 중에는 이미지 이동이 막힙니다.
  - ↑/↓: 이전/다음 오브젝트 선택(현재 프레임에 마스크가 없는 오브젝트는 건너뜀). Edit 중이면 편집 대상이 따라 바뀝니다.
  - 뷰포트 빈 곳 클릭은 선택을 유지하고, 오브젝트 패널 빈 곳 클릭은 선택을 해제합니다.
  - 포인트: 드래그 = 이동(놓을 때 SAM2 재실행), 더블클릭 = 삭제.
  - 휠 = 줌, Ctrl+휠 = 브러쉬 크기
  - 가운데 버튼 드래그 또는 Space+드래그 = 화면 이동
- **도움말:** Help → Keyboard Shortcuts(`F1`)에서 전체 단축키를 볼 수 있습니다.

### 3단계 · 프롬프트 / 디텍션 (`v0.3-p3`)
- **Batch 탭 분리:** 배치 마스킹을 `Batch` 탭으로 분리했고, 프롬프트 입력도 따로 있습니다.
- **Preview 버튼:** 디텍션 후보 마스크를 화면에서 켜고 끕니다.
- **추가 방식 세 가지** (모두 Undo 1단계)
  - `Add Each`: 체크한 후보마다 오브젝트 하나씩
  - `Add as One`: 체크한 후보를 머지해서 오브젝트 하나(첫 번째 라벨 이름)
  - `Add per Prompt`: 프롬프트(라벨)별로 오브젝트 하나씩
- **뷰포트에서 후보 선택: `Select on Image` 토글** (Preview 옆)
  - 디텍션이 끝나면 자동으로 켜지고, 켜져 있을 때만 뷰포트에서 선택합니다. Add/Discard로 목록이 비면 꺼집니다.
  - 클릭 / 드래그: 추가 · Shift: 토글(노란 박스) · Ctrl: 해제(빨간 박스)
  - 드래그 박스에 조금이라도 걸린 후보가 대상입니다. 겹친 곳을 클릭하면 가장 작은 후보가 대상입니다.
  - 켜져 있는 동안에는 Edit·New Object에 들어갈 수 없습니다(편집 중이었다면 켜질 때 종료).
  - 체크 해제된 후보도 외곽선이 남아서 위치와 모양이 보입니다.
- **첫 클릭 오브젝트 생성 제거:** 오브젝트가 없어도 일반 클릭으로는 오브젝트가 생기지 않습니다. `N` 또는 `+ New Object from Points`로 만듭니다.

### 4단계 · 오브젝트 관리 (`v0.3-p4`)
- 오브젝트는 기획서대로 모든 프레임에 걸친 하나의 대상이고, 데이터 구조는 그대로 뒀습니다(A안).
- 목록에는 현재 프레임에 마스크가 있는 오브젝트만 보입니다. 목록 위 `Show all Objects`를 켜면 전부 보이고, 편집 중인 오브젝트는 항상 보입니다.
- 숨긴 오브젝트가 있으면 "2 of 3 shown"처럼 개수를 표시합니다.
- 두 프레임 이상에 마스크가 있는 오브젝트(전파·배치 등)는 이름 옆에 `🔗 N`(프레임 수)을 표시합니다.

### 5단계(일부) · 전파 범위와 재개 (`v0.3-p5a`)
- **Reference:** 이미지 목록에서 더블클릭한 이미지가 전파 기준이 됩니다(목록에 ◎, Propagation 탭에 표시). 다시 더블클릭하면 해제되고 현재 이미지가 기준이 됩니다.
- **Scope 드롭다운**
  - `Selection`(기본): 이미지 목록에서 Shift/Ctrl로 고른 이미지. 사이의 이미지는 건너뛰고 이어 붙여 전파합니다.
  - `Range`: Start~End
  - `All images`: 전체
- **📌 Pin:** 지금 목록 선택을 고정합니다. 이후 목록을 클릭해 이미지를 넘겨도 범위가 유지됩니다.
- **Stop / Cancel**
  - Stop: 멈출 때까지 전파된 프레임을 남깁니다.
  - Cancel: 이번 실행 결과를 전부 버리고 전파 전 상태로 둡니다.
  - Stop을 누른 뒤 멈추는 중에도 Cancel을 누를 수 있습니다(버리기로 전환). 배치 마스킹도 같습니다.
- **Resume:** Stop이나 오류로 멈춘 전파를 방향마다 마지막으로 도달한 프레임에서 이어갑니다.

### 5단계(일부) · 이미지 ID와 범위 입력 (`v0.3-p5b`)
- 이미지 목록 각 행 앞에 순서 ID(1부터)가 붙습니다.
- Propagation의 Range는 드롭다운 대신 ID를 입력합니다(`5 ~ 45`, `5-45`, 한 장이면 `7`). 범위를 벗어나면 안내가 나오고 실행되지 않습니다.
- Pin된 이미지는 목록에서 노란 배경과 📌로 표시되고, Propagation 탭에는 `Pinned: 3–5, 12 (4 image(s))`처럼 ID로 보입니다.
- Reference 아래에 "이미지 목록에서 더블클릭하면 기준 이미지가 된다"는 안내가 있고, 이미지 목록 툴팁에도 조작법을 적었습니다.

### 5단계 · 레이아웃 (`v0.3-p5`)
- **하단:** 프레임 목록이 가로 썸네일 줄이 됐습니다.
  - 각 칸에 ID·상태 표시·◎·📌와 파일명이 붙습니다.
  - 클릭, Shift/Ctrl 선택, 더블클릭(기준 이미지), Pin 표시는 그대로 동작합니다.
  - 썸네일은 화면에 보이는 칸만 조금씩 읽어서 이미지가 많아도 멈추지 않습니다.
- **왼쪽:** 오브젝트 목록 아래에 Prompt/Detection · Batch · Propagation · Logs 탭이 있습니다. 폭에 맞게 Propagation·Batch·Detection 패널을 세로로 재배치했습니다.
- **오른쪽:** Properties는 그대로입니다.
- **원복:** 레이아웃만 되돌리려면 `git revert -m 1 0fee2be`, 레이아웃 전 상태 전체는 태그 `before-p5-layout`입니다.

### 5단계 보완 · 세로 프레임 리스트, 범위 입력, 썸네일 (`v0.3-p5c`)
- **세로 프레임 리스트:** 창 맨 왼쪽의 좁은 `Frame List` 독에 한 줄씩 `ID  상태 ◎ 📌  파일명`으로 보여줍니다.
  - 하단 썸네일 줄과 데이터·선택을 공유해서 현재 이미지, Shift/Ctrl 선택, ◎, 📌가 항상 같습니다.
  - 더블클릭하면 기준 이미지로 지정됩니다.
- **View 메뉴:** Frame List / Objects 열 / Properties / Frames 줄을 켜고 끕니다.
- **이름 접기:** Frame List 제목줄의 닫기 버튼 왼쪽 `Aa` 버튼으로 파일명을 접으면 ID와 표시만 남고 리스트가 좁아집니다. 상태는 다음 실행에도 유지됩니다.
- **S / Go to:** `S` 키나 각 창 아래 줄의 ⌖ 버튼으로 현재 프레임 위치로 스크롤합니다(하단 줄은 정중앙). 같은 줄의 `Go to ID` 칸에 ID를 입력하고 Enter를 누르면 그 프레임으로 이동합니다. Frame List에는 가로 스크롤바가 생기지 않습니다.
- **Range:** Start·End 두 칸으로 입력합니다.
- **Scope `Custom (IDs)`:** `1-4, 35, 23`처럼 ID와 범위를 섞어 입력합니다.
- **썸네일**
  - 프로젝트 옆 `images.sms/thumbs/`에 캐시합니다.
  - 약 8ms씩 몰아서 읽고, 보이는 칸을 먼저 한 뒤 나머지를 쉬는 시간에 전부 미리 읽습니다.
  - 실사 123장 기준: 처음 9.6초(최대 멈춤 93ms), 두 번째부터 0.3초(최대 멈춤 17ms)
- 왼쪽 열 패널들이 좁은 폭에 맞춰 줄어들게 해서 캔버스가 넓어졌습니다.

## 진행 예정

### 6단계 · COLMAP
- COLMAP 형식 읽기: 이미지와 마스크를 맞춰서 원본 마스크를 오브젝트로 불러옵니다.
- 편집 결과를 bin 파일에 반영합니다(프레임 삭제 대비).
- 마스크를 여러 버전(여러 폴더)으로 내보냅니다.
