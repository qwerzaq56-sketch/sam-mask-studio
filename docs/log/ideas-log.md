## `v0.4-p8` · 키프레임 이동, 기준으로 이동

> 키프레임 오브젝트가 있는(전파 소스) 프레임을 순회하는 기능과 단축키. 현재 프레임에서 앞/뒤로 가장 가까운 곳으로. `[ ]`나 `, .`에.

- `,` / `.` = 가장 가까운 이전 / 다음 ★ 프레임(Frame List `1`이 켜져 있으면 선택한 Object의 ★만). `[ ]`는 문제 프레임(⚠ ✕)이 이미 씀.

> 선택한 프레임으로 이동(S)이 Shift 선택 끝으로 감. 의도는 더블클릭한 위치. F나 R 쪽으로.

- `F` = 기준(◎, 더블클릭한 프레임)으로 이동. 원래 `F`(Show Changes)는 `R`로.

> 단축키 목록을 정리하는 문서.

- [`keymap.md`](../design/keymap.md): 현재 키맵, 비어 있는 키, 제안.

## `v0.4-p15` · 키와 메뉴 손보기

> Go 메뉴의 Scroll to Current Frame(S)은 F와 겹치고 작동도 안 됨. 빼기.

> V에 매핑된 기능 이름은 상단 메뉴에서 "Final/Object 마스크 토글"로.

- 메뉴 `Toggle Final / Object Mask`, 툴바는 지금 모드(`Preview: Final`).

> X 꾹 누르면 연속으로 바뀜. Z = 홀드, X = 모드 변경, V = 토글로.

- `Z` 누르고 있기 · `X` Final ↔ Object · `V` 켜기/끄기. 토글 키는 누르고 있어도 한 번만.

> 프레임 선택 엔터 말고 스페이스도.

- 프레임 목록 위에서 `Space` = `Enter`(기준 ◎). 캔버스의 Space+드래그는 그대로.

> Paint 버튼으로 넘어가도 A처럼 전체가 찬 상태로 시작.

- Paint 버튼 = `A`.

> 에딧모드 처음 진입하면 브러쉬 켜기. UX 원칙을 세우고 문서로.

## `v0.4-p17` · Objects 패널

> 삭제 시 물어보지 않고 대신 잠금(어차피 언두 됨). 모든 오브젝트 잠금/해제 버튼.

- 삭제는 확인 없이(Ctrl+Z). 행마다 🔒, `🔒 All` / `🔓 All`. 잠긴 Object는 삭제·Merge로 사라지지 않음. 잠금도 Undo, 저장됨.

> 오브젝트 패널에 마우스오버 시 Ctrl+D 복제, Ctrl+Shift+D 링크드 복제.

- 그대로 구현. 메뉴 Edit → Objects에 키 표시.

> 선택 기반 카피는 첫 선택이 소스, 마지막 선택이 타겟. 설명 가능한 걸 선택지로 쥐여주지 않기.
> 머지는 옵션 없이 Add. 옵션을 남기면 "내용만 머지하고 오브젝트는 비우기"도.
> 카피는 Add + 현재 이미지로, 옵션 버튼은 오른쪽에 작게.

- `Copy A → B` / `Merge` = 바로 실행, 옆 `⚙` = 옵션(Copy: Add / Replace, 이 이미지 / 모든 이미지 · Merge: Add / Override A / B / Into A).
  (Copy / Move / Merge 역할 재정리: [`specs/05-merge-copy-move.md`](../specs/05-merge-copy-move.md))

## `v0.4-p19` · p16~p18 수정 피드백

> 잠금 / 해제 버튼이 같은 아이콘. 안 잠겼을 때는 빈 칸, 잠겼을 때만 자물쇠(안 잠겼을 때 부담스럽지 않게).

- 행의 잠금 칸: 안 잠김 = 빈 칸(마우스를 올리면 흐린 🔒), 잠김 = 🔒. 위쪽 버튼은 `Lock All` / `Unlock All`.

> 현재 프레임은 칠, 엔터로 고른 프레임은 테두리. 파랑은 눈에 안 띄니 색 변경.

- 열린 프레임 = 파랑 칠(흰 글자), 기준 ◎ = **주황 테두리**, Shift/Ctrl 선택 = 옅은 파랑.

> 뷰포트에 마우스가 있으면 W / S = 오브젝트 전환. 맨 위에서 W → 맨 밑, 맨 밑에서 S → 맨 위.

- 캔버스 위 `W` / `S` = Objects 목록의 이전 / 다음 행. 순환은 Object 이동 전체(목록 위 키, `↑` `↓`)에 같이 적용.

## `v0.4-p20` · Merge / Copy / Move 역할 나누기

> 머지 / 카피 외에 무브 추가, 각 기능 역할 분리. 머지 = 합치고 소스 삭제(링크드 오브젝트 결합), 옵션 Add / Override A / B, Into A는 무브로.
> 무브 = 소스에서 없애고 타겟으로(레이어 분리, 분리 레이어 유지). 카피 = 소스 유지. 무브 / 카피 옵션: Add / Replace, 현재만 / 전체.
> 카피 / 무브는 한 버튼, 기본 = 무브 A → B, Add, 현재만. 옵션 최상위에 무브 / 카피.

- 기획서 [`specs/05-merge-copy-move.md`](../specs/05-merge-copy-move.md). 범위 = 이 이미지 / 모든 이미지, Move = Mask 전체, 옵션은 기억 안 함.
- `Move A → B` 버튼(Move · Add · 이 이미지) + `⚙`(Move / Copy · Add / Replace · 범위). Merge `⚙`에서 Into A 제거. `[···]` ▸ Move into / Copy into.

- Edit 중 **Ctrl+클릭** = 그 자리 조각 더하기, **Ctrl+우클릭** = 빼기. Edit Layer에 쌓여 나머지는 그대로, 클릭당 디코더 한 번.

## `v0.4-p45` · 에딧 모드 단축키

> E로 진입 시 브러쉬인 게 불편(포인트 에딧). D는 브러쉬 유지. 어플라이 & 클로즈 단축키 F?

- E = 포인트로 편집, D = 브러시(편집 중이 아니면 선택한 Object를 브러시로 편집 시작), Apply & Close = Shift+Enter(F는 Go to Reference가 사용 중).
