# UI 이슈 목록

쓰다가 거슬리는 것을 한 줄씩 적어두는 곳입니다. 기능 아이디어는 [`ideas.md`](ideas.md)에 적습니다.

- 새 이슈는 맨 아래 "사용자 메모"에 한 줄씩: 무엇이 / 어디서 / (캡처 파일 이름). 캡처는 `docs/ui-shots/`에.
- 정리할 때 번호를 붙여 "열린 이슈"로 옮기고, 고치면 "완료"로 옮기며 태그를 적습니다.

## 완료

### `v0.4-p6` · 개선 (2026-09-29)
- 7. 상태(편집, 디텍션)에 따라 패널 폭이 바뀌어 캔버스가 좌우로 움직임 → 작업 상태 바는 넘치면 잘리게, 디텍션 안내는 줄바꿈
- 8. 선택이 없을 때 Properties에 빈 칸·회색 버튼이 가득 → 제목과 안내만 표시
- 9. 캔버스 왼쪽 위 배너가 작업 상태 바와 중복 → 배너 제거
- 10. Propagation 탭: 실행 전에도 진행 막대·빈 상자, 버튼 폭 불일치 → 첫 실행부터 표시, Propagate 버튼 한 줄 전체
- 11. Batch 탭: 실행 전에도 진행 막대·빈 결과 상자 → 첫 실행부터 표시
- 12. 오토 툴 Settings 상자 아래 빈 공간 → 지금 도구 설정 높이에 맞춤
- 14. 오토 툴 Fill 설명 문구가 4~6줄 → 한두 줄로
- 15. 작업 중에도 캔버스에 `Select on Image` 안내가 남음 → 배너 제거로 해결

### `v0.4-p5` · 버그 (2026-09-29)
- 1. Batch 탭 `Run on Images` / `Stop` / `Cancel` 버튼이 너비 0으로 사라짐
- 2. Frames 줄 개수 요약이 세로로 한 글자씩 쌓임
- 3. Frames 줄 썸네일 아래 ID와 ★ ✓ 표시가 잘림
- 4. Frame List에서 10번부터 표시와 이름이 한 칸 밀림
- 5. 버튼 글자 잘림(`elect on Imag`, `dd per Promp`, 탭 `Propagat` 등)
- 6. Propagation 탭 문구에 옛 이름 `Images list`

### `v0.4-p4.1` · 버그
- 파일 이름을 접은 상태(`Aa` 꺼짐)로 시작하면 Frame List가 넓게 뜸, `Aa`를 두 번 눌러야 좁아짐
