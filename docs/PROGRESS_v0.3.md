## 완료

### 1단계 · 반응 속도 / 작은 UX 수정 (`v0.3-p1`)
- **프롬프트 체크박스 토글이 느리던 문제 해결**
  - 원인: 체크 하나마다 화면 전체 갱신이 여러 번 돌았습니다. 라벨 체크박스는 후보 수만큼 돌았습니다.
  - 결과: 0.8초 → 0.02초
- **캔버스 오버레이 캐시:** 바뀐 레이어만 다시 그립니다.
- **외곽선:** 흰색 1줄. 줌해도 굵어지지 않고, 툴바에서 켜기/끄기(`O`)와 두께를 조절합니다.
- **에딧 레이어 초록/빨강 표시:** 기본은 끄고, 툴바 `Edit Changes`로 켭니다.
- **오브젝트 행 버튼:** 선택 안 된 행의 버튼이 두 번 눌러야 동작하던 문제를 고쳤습니다.
- **배치 마스킹 / 전파:** `Stop`(여기까지 결과 유지)과 `Cancel`(전부 버림)을 분리했습니다.
- **자동 저장:** 백그라운드로 옮겨서, 배치·전파 직후 몇 초씩 멈추던 문제를 없앴습니다.

### 2단계 · 에딧 레이어 도구 (`v0.3-p2` ~ `v0.3-p2.10`)
- **머지 이름:** 처음 선택한 오브젝트의 이름을 씁니다.
- **프로퍼티 창:** `Mask` / `Edit Layer` 탭으로 나누고, 탭마다 스크롤할 수 있습니다.
- **Brush 그룹** (칠하는 즉시 반영)
  - `Paint`: 드래그 = 추가, Alt+드래그 = 빼기. 단축키 `B`.
  - `Restore`: 칠한 곳의 편집을 되돌립니다. 옵션은 `Add` / `Subtract` / `Both`.
- **Auto tools:** `Object Fill` / `Fill Holes` / `Remove Specks` / `Grow` / `Shrink`
  - 툴을 누르면 결과를 바로 계산합니다. Object Fill은 백그라운드로 계산합니다.
  - `Fill` 모드(기본): 결과 전체를 마젠타(추가)/보라(제거)로 보여줍니다. 에딧 체인지의 초록/빨강과 구분됩니다.
  - `Paint` 모드:
    - 선택하지 않은 부분은 회색입니다.
    - 드래그하면 범위가 노란색으로 표시되고, 놓으면 그 부분이 선택되어 마젠타/보라가 됩니다.
    - Alt+드래그는 선택 해제입니다(범위가 빨간색으로 표시).
    - `A`는 전체 선택, 다시 누르면 전체 해제입니다.
    - 선택·해제·전체 선택도 Ctrl+Z / Ctrl+Y로 되돌릴 수 있습니다. 반영한 뒤에는 Ctrl+Z가 반영 자체를 되돌립니다.
  - 반영 시점 (반영할 때마다 Undo 1단계)
    - 같은 툴 버튼을 다시 누르면: 반영하고 툴은 유지합니다. 누를 때마다 한 번씩 더 적용됩니다(예: Grow 3번).
    - `Apply` 버튼: 반영하고 나갑니다.
    - 다른 툴 선택, Finish Editing, 이미지·오브젝트 이동: 반영하고 나갑니다(Fill은 전체, Paint는 선택한 부분).
    - `Esc`: 반영하지 않고 나갑니다.
  - `Region Box`: 드래그로 범위를 추가하고, Alt+드래그로 뺍니다. 오토 툴은 이 범위 안에서만 동작하고, 리전 조작도 Undo가 됩니다.
  - 설정: 툴마다 따로 가지며 슬라이더 + 입력 칸입니다. 슬라이더 위에서 휠을 굴리면 값은 그대로 두고 패널이 스크롤됩니다.
    - Object Fill: `Max grow`, `Sensitivity`
    - Fill Holes / Remove Specks: `Max size`를 각각 따로 가집니다.
    - Grow / Shrink: 공통 `Amount`
- **파이널 마스크 프리뷰**
  - `Z`를 누르고 있는 동안 보이고, `X`로 켜고 끕니다.
  - 프리뷰 중에도 편집할 수 있고, 브러쉬 반경은 초록색으로 보입니다.
- **Alt 표시:** Alt를 누르고 있으면 브러쉬 반경 원과 리전 박스 드래그 사각형이 빨간색으로 바뀝니다(빼기·선택 해제 구분).
- **조작**
  - 이미지 넘기기: ←/→, PgUp/PgDown (A/D는 제외. A는 Paint 모드 전체 선택 전용)
  - 휠 = 줌, Ctrl+휠 = 브러쉬 크기
  - 가운데 버튼 드래그 또는 Space+드래그 = 화면 이동
- **도움말:** Help → Keyboard Shortcuts(`F1`)에서 전체 단축키를 볼 수 있습니다.

## 진행 예정

### 3단계 · 프롬프트 / 디텍션
- 배치 마스킹 탭을 현재 이미지 디텍션과 분리하고, 프롬프트 입력도 따로 둡니다.
- 디텍션 마스크 프리뷰 켜기/끄기 버튼
- 선택한 디텍션을 머지해서 오브젝트 하나로 추가, 또는 프롬프트별로 오브젝트 추가
- 뷰포트에서 Shift/Ctrl 클릭·드래그로 디텍션 선택/해제

### 4단계 · 오브젝트 관리
- 현재 프레임에 마스크가 없는 오브젝트는 기본으로 숨기고, 옵션으로 보이게 합니다.
- 전파된 오브젝트에 "링크드" 표시

### 5단계 · 레이아웃
- 프레임 목록을 하단의 가로 썸네일로 옮깁니다.
- 전파 범위를 썸네일에서 A→B(Shift 선택)로 지정합니다.
- 프롬프트 / 디텍션 / 전파 / 로그 UI를 오브젝트·이미지 패널 아래로 옮깁니다.

### 6단계 · COLMAP
- COLMAP 형식 읽기: 이미지와 마스크를 맞춰서 원본 마스크를 오브젝트로 불러옵니다.
- 편집 결과를 bin 파일에 반영합니다(프레임 삭제 대비).
- 마스크를 여러 버전(여러 폴더)으로 내보냅니다.
