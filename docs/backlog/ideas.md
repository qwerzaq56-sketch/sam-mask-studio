## 에딧모드 편집 (완료, v0.4-p49 — 써 보고 추가 피드백 예정)

ux적으로 지금

D로 에딧모드 + 브러쉬 진입
E로 에딧모드 + 포인트 에딧 진입

이게 느껴지는데

D에서 E 누르면 에딧모드에서 나가짐
-> 이게 부자연스러움.

에딧 모드 안에서는 E,D로 왔다갔다하고

D 브러쉬모드에서 D 한번 더 누르면 에딧모드 나가지고
E 포인트 에딧 모드에서 E 한번 더 누르면 나가지고

이게 맞는 듯.

에딧모드가 상위 모드로서 하위 툴들을 계층적으로 포괄하고
현재 상태를 설명하므로 중요하긴 한데
하위 모드도 하나의 툴로서의 아이덴티티를 확실히 갖게 하는 방향성이 그거인 거 같음.

+오토 툴일 때 
A로 페인트 모드 진입이 조금 비직관적인 느낌인데.
D로 진입해야 할 것 같은 느낌.

내 감각상, 어플라이 & 엔터를 F로 가져가고. 
프레임 포커스의 F는 선택관련 창에 마우스오버 됐을 때로 제약을 두어서 한 단축키에 두 기능 공존하게.
그리고 오토 툴 활성화 되어있을 때는 D가 페인트 전환이 아니라 페인트 모드 진입/필 모드로 변경 토글이도록 하고.
A는 오토 툴을 끄는 쪽으로 매핑하면 될 것 같은데.

A/D는 화살표 뒤, 앞으로 매칭되기도 하니, A는 취소, D 옆의 F가 확인의 의미로 작동하면 좋지 않을까 하는 체감.
근데 해봐야 UX를 판단할 듯.

- (완료, v0.4-p49) E = 포인트 / D = 브러쉬, 같은 키 다시 = 편집 끝. 오토 툴: D = Paint / Fill, A = 나가기, F = 적용(프레임 목록 위나 오토 툴 없으면 기준 ◎). 전의 A는 Shift+A.

# 포인트 추가 (완료, v0.4-p53)
이거 각 오브젝트별로 포인트 레이어도 따로 있어야 되는게 맞아보임.

네거티브 포인트로 빼는 조작은 쓸만한데
포지티브 포인트로 넣는 조작은 오리지널 마스크 원형을 너무 훼손시킴.

기존 포인트 칸에 
레이어 + 드롭다운으로 하위 계층에서 포인트/박스 관리 가능. 
그리고 이 목록에서 포인트/박스 옆에 X 버튼 둬서 하나씩 삭제가 직관적이도록

기본적인 추가 조작은 자동생성되는 Layer 1번에서 수행되고,
현재 작업중인 레이어를 선택 가능 + 이후 조작은 선택된 레이어에서 수행.
오리지날 이미지를 가리키는 레이어도 존재해서 거기서 Edit하면 오리지날 마스크를 소스로 편집 수행 가능하게.
-> 이러면 될 거 같은데 UX나 예상되는 문제 검수해보고 작업

- (완료) 검토 결과와 결정은 [`specs/10`](../specs/10-prompt-layers.md). Points 칸이 트리(Original · Layer n (+/−) · 포인트 / 박스마다 ×),
  + Layer · + / − · Remove Layer. 자기 포인트 없이 생긴 마스크(불러오기 · 전파 · Apply)는 첫 클릭이 Layer 1(+).

## 에딧모드 UX

F가 어플라이 + 컨티뉴가 아니라
     어플라이 + 클로즈여야 함. 

A는 취소, F는 적용.

그리고 오토툴 모드에서
 페인트로 진입한 상태에서는 D한번 더 누르는 게 전체 채우기/빼기 토글이고
 S를 누르면 필 모드로 돌아오면 좋겠음. S/D 누르면 왔다갔다.

 D에서 ( 오토툴 페인트 ) 작업한 사항은 왔다갔다 하는 동안 유지되고. ( 실수 리스크 감소 )

A => F 가는 사이에 기능키들이 있는 느낌.

어플라이 + 컨티뉴는 G나 다른 키로 해도 될 듯.
