# UI 이슈 목록

쓰다가 거슬리는 것을 한 줄씩 적어두는 곳입니다. 기능 아이디어는 [`ideas.md`](ideas.md)에 적습니다.

- 새 이슈는 맨 아래 "사용자 메모"에 한 줄씩: 무엇이 / 어디서 / (캡처 파일 이름). 캡처는 `docs/backlog/ui-shots/`에.
- 정리할 때 번호를 붙여 "열린 이슈"로 옮기고, 고치면 "완료"로 옮기며 태그를 적습니다.
- 파일은 UTF-8로 저장해 주세요(메모장이면 "다른 이름으로 저장" → 인코딩 UTF-8).
