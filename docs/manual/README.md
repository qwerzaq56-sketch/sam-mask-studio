# SAM Mask Studio 사용 설명서

3DGS / COLMAP 학습에 쓸 마스크를 만드는 툴의 사용 설명서입니다.
SAM3가 글자로 대상을 찾고, SAM2가 클릭으로 따고 다듬고, SAM2 비디오가 여러 프레임에 전파합니다.
결과는 학습기(Spirula Studio, Brush, Postshot, COLMAP …)가 바로 읽는 흑백 마스크입니다.

## 읽는 법

- 버튼과 메뉴 이름은 앱에 보이는 영어 그대로 씁니다: **Propagate Selected Objects**, File → **Export Final Masks…**
- 키는 괄호 안에 씁니다: **Brush** (`D`). 모든 명령은 메뉴 바에도 키와 함께 있고, 앱에서 `F1`을 누르면 단축키 전체가 나옵니다.
- 📷 표시는 그림이 들어갈 자리입니다(그림은 준비 중).
